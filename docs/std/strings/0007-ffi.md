# FFI

**Status:** Implemented, see `docs/language/0048-ffi.md`

```ax
extern c puts(text: cstr)
```
Use `to_cstr()` for C interop.

Implemented as specced: `extern c name(params) [-> returnType]`
declarations, `cstr` (representationally identical to `str`, reachable
only via `.to_cstr()`), restricted to FFI-safe parameter/return types
(`i32`, `bool`, `str`, `cstr`, or no return type). The compiled backend
genuinely links against any correctly-declared C symbol; the interpreter
can only execute a small, explicit, hand-implemented allowlist (`puts`,
`abs`) - see `docs/language/0048-ffi.md`'s own Known Imprecision section
for why that gap is real and unavoidable, not an oversight.
