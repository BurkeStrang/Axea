# str

**Status:** Partially implemented - see `docs/language/0042-string.md`.

Immutable UTF-8 string view. `str` literals, passing by value, and use as
a `Map`/`Set` key already work - `.length` does not (`str` has no length
field of its own; only `String`'s own `.length` is implemented so far).
String interpolation (`"Hello {name}"`, shown below) is not implemented
yet either - no lexer/parser support exists for it.

```ax
greet(name: str)
{
    print("Hello {name}")
}
```
Passing `String` automatically lends a `str` - implemented (see
`docs/language/0042-string.md`'s own Design section for how the
"lending" is a real byte copy, not an alias, at both the interpreter and
LLVM layers).
