# str

**Status:** Mostly implemented - see `docs/language/0042-string.md`,
`docs/language/0047-unicode.md`, `docs/language/0045-str-slicing.md`, and
`docs/language/0051-numeric-widening.md`.

Immutable UTF-8 string view. `str` literals, passing by value, use as a
`Map`/`Set` key, ordering (`<`/`<=`/`>`/`>=`, real lexicographic byte
order), `.length`/`.bytes` (computed at runtime from the null-terminated
bytes, even though `str` has no stored length field of its own), and
single-character indexing (`s[i]`, a real Unicode *codepoint* index, not
a byte offset - returns a `char`, read-only) all work. String
interpolation (`"Hello {name}"`, shown below) is implemented too - both
the lexer/parser support and the `print(...)` builtin it's used with
here:

```ax
greet(name: str)
{
    print("Hello {name}")
}
```

Passing `String` automatically lends a `str` - implemented (see
`docs/language/0042-string.md`'s own Design section for how the
"lending" is a real byte copy, not an alias, at both the interpreter and
LLVM layers). `.parse<T>()` now covers `T ∈ {i32, i64, f64, bool}` (see
`0008-parsing-formatting.md`) and genuinely returns `Optional<T>` (see
`docs/language/0052-optional.md`) - invalid input is a real `None`, not a
silently-returned fallback.
