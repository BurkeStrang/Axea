# char

**Status:** Implemented, see `docs/language/0044-char.md`

Unicode scalar value.

```ax
'A'
'é'
'🚀'
```

Equality (`==`/`!=`) and ordering (`<`/`<=`/`>`/`>=`, by codepoint) are
implemented; arithmetic (`+`, `-`, ...) is deliberately not, mirroring
Rust's own choice. No `i32 <-> char` conversion, no escape sequences in
literals (`'\n'` etc.), and not a valid `Map`/`Set` key type this phase -
see `docs/language/0044-char.md`'s own Known Imprecision section.
