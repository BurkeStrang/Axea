# Axea Vision

## Mission

Axea is a modern systems programming language focused on compile-time
memory safety through inference instead of annotation.

### Tagline

> Safe by proof. Simple by inference.

## Core Principles

-   Inference First
-   Contracts When Needed
-   Zero-Cost Safety
-   Explicit Escape Hatches

## Long-Term Goals

-   Native performance
-   Excellent diagnostics
-   Ergonomic syntax
-   World-class tooling
